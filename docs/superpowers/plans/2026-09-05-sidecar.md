# Codex Sidecar Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan. Checkboxes track deliverables.

**Goal:** Ship an inspectable, open-source Windows companion with quota, a hover drawer, notes, and bookmarks.

**Architecture:** A Node coordinator attaches an isolated renderer over loopback CDP and reads quota through the official stdio app-server. A revisioned local store synchronizes windows without modifying official app data.

**Tech Stack:** Node >=22.13, TypeScript, esbuild, node:test; browser harness for integration.

**Spec:** ../specs/2026-09-05-sidecar-design.md

## Global Constraints

- No app.asar, signature, updater, authentication, or conversation database modifications.
- No forced or automatic restart of Codex; no global input interception.
- Use isolated components, literal text rendering, revision checks, loopback verification, and bounded reconnects.
- Runtime state stays outside source control. Preserve original license notices for borrowed code.
